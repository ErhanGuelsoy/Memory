# TS-Memory

A two-player Memory Game built with **TypeScript, Vite, HTML and SCSS**.

Choose between different themes, players and board sizes and play a classic Memory game with custom graphics.

## 🎮 Features

* Two-player gameplay
* 3 game themes: Code Vibes, Foods & Gaming
* 16, 24 or 36 cards
* Blue & Orange players
* Score tracking
* Winner & Draw screen
* Custom game graphics
* Settings saved with `localStorage`

## 🛠️ Technologies

* TypeScript
* JavaScript
* HTML5
* SCSS
* Vite
* CSS Grid & Flexbox
* LocalStorage

TypeScript files are compiled into JavaScript files during the production build. The generated JavaScript files are included in the `dist` folder and are used by the live version.

## 🚀 Installation

bash
git clone https://github.com/ErhanGuelsoy/Memory.git
cd Memory
npm install
```

## 💻 Development

bash
npm run dev

## 🏗️ Build

bash
npm run build


The production build is generated in the `dist` folder. Vite compiles the TypeScript source code into JavaScript files for production.

## 🌐 Live Version

The production version of the Memory Game is available online.

The live version uses the generated files from the `dist` folder, including the compiled JavaScript files.
